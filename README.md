# Arietta

> 名字取自意大利语 *arietta*（*aria* 的指小形式，即「小咏叹调」；该词另有「微风」之义）

Arietta 是社区非商业的第三方库洛游戏启动器，用来补上官方启动器缺的那些体验。它支持 Kuro Games 旗下全部 PC 游戏——鸣潮与战双帕弥什，国服、B 服、国际服等 8 个服务器，数据按服隔离。

除了选服、启动、更新这些基本功能，我按自己的使用需求加了不少东西：

- **游戏时长记录** —— 只统计由本启动器启动的对局；累计时长、启动次数、游玩天数、单局最长，以及近 15 天 / 12 周 / 12 个月的柱状图
- **抽卡记录** —— 导入唤取链接自动抓取；卡池分析、垫抽数、5★ / 4★ 占比与清单，口径对齐 paimon.moe
- **库街区** —— 每日签到与月签日历、我的角色养成、鸣潮深塔 / 冥歌·海墟 / 末日矩阵、战双资源月报与战绩数据
- **截图管理** —— 自动定位游戏截图目录、按日期分组浏览、批量删除进系统回收站
- **安装与更新** —— 资源三档自选（UHD / HD / SD）、差分与 krzip 组补丁、断点续传、多连接分段加速、预下载、文件校验与损坏修复
- **游戏内设置** —— 显示模式、分辨率、HDR、语音语言，以及手柄按键映射
- **动态背景** —— 拉取官方动态背景或自备图片 / 视频；主色提取自动切换全局主题强调色
- **WebDAV 同步** —— 单库双锚点增量同步，同步前自动备份并滚动保留历史版本
- **工具箱** —— ADB 串口模拟器、库街区 token / did 抓取

界面支持简中 / 繁中 / 英 / 日 / 韩 / 法 / 德 / 西班牙 / 泰 / 巴西葡语 10 种语言，可热切换无需重启。

还有其他功能等你探索。

## 安装

发布版是免安装压缩包，解压后双击 `Arietta.exe` 即可。所有数据默认存放在 exe 同级的 `Arietta\` 目录下，整个目录拷走就能迁移。

- **系统要求**：Windows 10 1809（build 17763）及以上，x64
- 已安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2)
- 已安装 [WebP 映像扩展](https://apps.microsoft.com/detail/9pg2dk419drg)
- 为了更好的使用体验，请在系统设置中开启**透明效果**和**动画效果**

然后在 [GitHub Release](https://github.com/Pizazz-stack/Arietta/releases) 下载对应 CPU 架构的压缩包，解压后运行 `Arietta.exe` 并按提示操作

## 开发

在本地编译应用，你需要安装最新版的 Visual Studio 并选择以下负载：

- .NET 桌面开发
- 使用 C++ 的桌面开发
- 通用 Windows 平台开发

## 数据与隐私

- 数据默认不出本机；只有用户主动配置了 WebDAV，云同步才会发生
- 本项目没有任何服务端，库街区登录态与抽卡链接只在本机与官方接口之间使用
