This folder is empty in the repository (font files are excluded by `.gitignore`). The build needs this file placed here:

    XboxFluent2.ttf

Sources: `Assets/Font/XboxFluent2.ttf` from a local Starward installation (e.g. `D:\Game Tools\Starward\app-<version>\Assets\Font\`), or download it from the Xbox Design System (design.xbox.com).

Without it the app still runs, but gamepad glyphs (the navigation gamepad icon, the Guide orb badge, the share button) render as empty boxes.
